# 실제 목소리·아이폰 검증

자동 검증과 실제 기기 검증의 결과를 분리해 기록합니다. WebKit의 iPhone 화면 설정은 실제 iOS 마이크, 오디오 재생, 앱 전환을 대신 검증하지 않습니다.

## 자동 검증 재실행

로컬 프론트엔드와 백엔드를 실행한 뒤 합성 테스트 음원을 준비합니다.

```bash
cd backend
.venv/bin/python -m scripts.smoke_analysis
cd ../frontend
npx playwright install webkit
npx playwright test --config playwright.webkit.config.ts
```

WebKit 테스트는 파일 업로드, 실제 Basic Pitch 분석, 터치 음정 수정, 길이 조절, 실행 취소, 임시 저장과 새로고침 복원, 320px 화면 가로 넘침을 확인합니다. 기본 Chromium 테스트는 기존 `npx playwright test`로 실행합니다.

## 실제 기기 확인 순서

주소: https://hum-phase1.vercel.app

무료 배포의 프로젝트는 재시작 시 사라질 수 있으므로 테스트용 녹음을 사용합니다. 첫 분석은 수 분 걸릴 수 있습니다.

1. 아이폰 Safari에서 열고 기종과 iOS 버전을 기록합니다.
2. 새 노래 만들기 → 흥얼거리기 → 녹음 시작 → 마이크 허용을 누릅니다.
3. 조용한 곳에서 한 음씩 10초 정도 부른 뒤 정지합니다. 원본 미리 듣기에서 실제 목소리와 길이가 정상인지 확인합니다.
4. 분석을 시작하고 대기 시간과 오류 여부를 기록합니다. 분석 중 새로고침한 뒤 진행 상태가 복원되는지 확인합니다.
5. 원본과 멜로디를 번갈아 듣고 음 높이, 음 개수, 길이 차이를 기록합니다. 허밍과 가사를 붙인 노래를 각각 확인합니다.
6. 음표를 터치해 음정과 길이를 바꾸고 멜로디 듣기로 변경을 확인합니다.
7. 이름을 입력하고 임시 저장 → 새로고침 → 수정 내용 복원을 확인합니다.
8. 멜로디 확정 → 저장 → 홈에서 다시 열기를 확인합니다.
9. 별도 녹음에서 마이크 권한 거부, 2초 미만 녹음, 녹음 중 화면 잠금·다른 앱 전환 후 복귀 시 오류나 재녹음 가능 여부를 확인합니다.
