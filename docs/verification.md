## 구분해서 볼 결과

모델에 직접 전달한 WAV는 8음을 정확히 검출했습니다. 같은 테스트 음원을 가상 마이크 → 브라우저 압축 녹음으로 전달한 경우에는 추가적인 짧은 음표가 검출되기도 했습니다. 따라서 합성 WAV 성공을 실제 노래의 정확도 보장으로 해석하면 안 됩니다.

이 환경에서 실제 사람 목소리나 물리 마이크를 대신 테스트하지 않았습니다. 사용자 본인이 약 10초 흥얼거려 보는 확인이 남아 있습니다. 실제 iOS/Safari 녹음도 별도 확인이 필요합니다.

## 빌드 도구

Turbopack의 프로덕션 빌드에서 보조 프로세스의 포트 바인딩 권한 오류가 발생했습니다. `npm run build`는 Next.js 공식 `--webpack` 옵션을 사용하도록 변경했습니다. 로컬 개발 서버의 Turbopack 동작과 브라우저 테스트는 정상입니다.

STT는 공급자 인터페이스와 수동 입력만 구현했습니다. Phase 2A의 악기 선택은 구현했으며, AI 편곡, AI 보컬, 믹싱/마스터링, 음원 유통, 결제는 구현하지 않았습니다.
